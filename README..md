
# Nexora Technologies – Responsive Company Website

A modern, responsive multi-page company website developed as part of the WeIntern Full Stack Development Internship – Week 2, Task 1.

## Live Website

https://preetamsalunke.github.io/nexora-company-website/

## GitHub Repository

https://github.com/PreetamSalunke/nexora-company-website

## Project Overview

Nexora Technologies is a fictional IT solutions company. This project demonstrates the development of a professional business website using HTML, CSS, and JavaScript.

The website includes four responsive pages, a mobile navigation menu, reusable design patterns, and client-side contact form validation.

## Features

- Responsive multi-page website
- Modern and consistent corporate design
- Mobile-friendly hamburger navigation
- Sticky navigation bar
- Home page with services overview
- About page with mission, vision, and team sections
- Services page with service cards and development process
- Contact page with JavaScript form validation
- Responsive footer across all pages
- CSS Flexbox and Grid layouts
- Desktop, tablet, and mobile support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media Queries
- Git and GitHub
- GitHub Pages

## Website Pages

### Home
Includes the hero section, services overview, and company benefits.

### About
Includes company introduction, mission, vision, and team information.

### Services
Displays technology services and the development process.

### Contact
Includes contact information and a validated enquiry form.

Note: The contact form is a frontend demonstration. It does not send emails or store submissions.

## How to Run Locally

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Navigate between the four pages.

## Responsive Design

The website uses flexible layouts, CSS Grid, and media queries to adapt to desktop, tablet, and mobile screens.

## Form Validation

The contact form validates:

- Full name
- Email address
- Subject
- Message

Invalid inputs display error messages, while valid inputs display a demo confirmation.
