
# Nexora Technologies – Design Documentation

## 1. Project Objective

To design and develop a professional, responsive multi-page company website using HTML, CSS, and JavaScript.

## 2. Design Theme

The website follows a modern corporate IT design with a clean layout, readable typography, and consistent visual elements.

## 3. Color Palette

- Primary Navy: #101d3a
- Accent Cyan: #00bcd4
- Text: #263248
- Muted Text: #64748b
- Light Background: #f3f7fb
- White: #ffffff

## 4. Typography

Inter is used as the primary font to maintain a modern and readable interface.

## 5. Website Structure

The website contains four pages:

1. Home
2. About
3. Services
4. Contact

## 6. Layout Techniques

- Flexbox for navigation and content alignment
- CSS Grid for service cards and multi-column sections
- Media queries for responsive layouts
- Consistent spacing and reusable design styles

## 7. Responsive Design

The layout adapts to different screen widths.

Desktop:
Multi-column layouts with horizontal navigation.

Tablet:
Reduced grid columns and adjusted spacing.

Mobile:
Single-column layouts and hamburger navigation.

## 8. JavaScript Functionality

Navbar:
Toggles the mobile navigation menu.

Contact Form:
Validates required fields and displays feedback.

## 9. User Experience

The design focuses on:

- Simple navigation
- Clear content hierarchy
- Readable typography
- Consistent branding
- Accessible form labels
- Responsive layouts

## 10. Project Limitations

The contact form uses client-side validation only.

No backend, database, or email delivery service is connected.

## 11. Conclusion

The project demonstrates responsive web design, multi-page navigation, CSS layout techniques, and basic JavaScript interactivity.
